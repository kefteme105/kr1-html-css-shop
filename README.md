# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — страница каталога;
- `contacts.html` — страница контактов;
- `product.html` — подробности товаров и характеристики;
- `order.html` — самостоятельная форма заявки;
- `css/style.css` — файл стилей;
- `js/main.js` — логика формы и модального окна;
- `images/` — папка для изображений;
- `sitemap.xml` — карта страниц сайта;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML;
- CSS;

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Реализованные элементы интерфейса

- кнопки заказа в карточках товаров;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация;
- базовая JavaScript-обработка формы;
- сообщение об успешной отправке.

## Многостраничная структура

- единая навигация на главной странице, в каталоге и на странице контактов;
- хлебные крошки на внутренних страницах;
- уникальные `title` и `description` для каждой страницы;
- якорные ссылки и визуальное состояние `:target`;
- Open Graph-метаданные и карта сайта `sitemap.xml`.

## Использование Flexbox и Grid

- Flexbox используется в шапке, навигации, карточках товаров и элементах формы;
- блок `.products-grid` формирует сетку карточек товаров;
- макет каталога `.catalog-layout` разделён на фильтры и товары через `grid-template-areas`;
- форма фильтров построена на CSS Grid;
- на узких экранах колонки каталога перестраиваются в один столбец.

## Практическая работа №7 — БЭМ

Проведён аудит: `page-header`, `site-logo`, `form-field`, `form-actions` заменены смысловыми классами. Шапка — `site-header`, внутренний контейнер — `site-header__inner`. Навигация, карточки, форма, диалог и хлебные крошки имеют собственные элементы. Состояние текущей страницы задаётся `site-nav__link--active`, вариант сетки — `products-grid--catalog`. Стили заголовков и полей больше не зависят от вложенных HTML-тегов. ID остаются для label, якорей и JavaScript.

Для защиты: объяснить блок, элемент и модификатор; показать одинаковую карточку на двух страницах и связь CSS-классов с HTML. Открытие диалога использует прежний `product-card__button`, поэтому JS-селектор сохранён.

Проверка №7: в браузере открыта главная, диалог открылся, пустая форма выделила пять обязательных полей; корректная учебная заявка закрыла диалог и показала сообщение. Внешний вид карточек и шапки проверен визуально.

## Практическая работа №8 — завершение КР №1

Добавлены `product.html` (изображения, описание, характеристики трёх товаров) и `order.html` (самостоятельная форма). Все пять страниц связаны общей навигацией. В `images/` находятся собственные SVG-иллюстрации. Карточки используют relative/absolute для метки, шапка — sticky, ссылка «Наверх» — fixed. Карта сайта обновлена.

`js/main.js` обслуживает нативный dialog и обе формы: сначала Constraint Validation API, затем локальное сообщение. На странице товара ссылка передаёт номер товара в query-параметре; разрешены только 1, 2, 3. Персональные данные не сохраняются и не отправляются. Фильтры каталога — явно обозначенный статический макет по условиям КР №1.

### Запуск и ручная проверка

Открыть `index.html` либо выполнить в папке проекта `python3 -m http.server 8000` и перейти на http://localhost:8000. Сборка, npm и сервер приложения не нужны.

1. Открыть пять страниц из меню и товар из каталога.
2. В таблице проверить характеристики и цену, перейти к заявке на товар 2.
3. Отправить пустую форму: должны появиться ошибки.
4. Заполнить имя, e-mail, телефон по подсказке, тему и согласие; отправить и увидеть демонстрационное сообщение.
5. На главной открыть диалог, закрыть кнопкой и Escape; проверить якорь и ссылку «Наверх».
